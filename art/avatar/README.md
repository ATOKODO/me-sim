# Sources de l’avatar

Conserver ici les fichiers de travail modifiables de l’artiste (`.blend`, textures sources et références). Exporter chaque animation finale en GLB autonome dans `public/avatar/clips/` et déclarer le fichier dans `public/avatar/animations.json`.

Voir [le guide de création et d’intégration](../../docs/artist-animation-guide.md).
