# Contributions

Me-Sim is currently maintained without accepting external contributions. Please do not open pull requests or send unsolicited patches; they will not be reviewed or merged at this stage.

You are welcome to clone, study, run, fork, modify and redistribute the code under **AGPL-3.0-only**. This contribution policy does not restrict the rights granted by the license. Third-party assets and dependencies retain their own terms; see [CREDITS.md](CREDITS.md) and [the license review](docs/licenses.md).

No commitment to support forks or review changes is made. If this policy changes, this document will be updated.
